# VA CFR Finder (MVP)

An educational tool to map common conditions to 38 CFR rating references. This tool is designed to assist veterans in navigating the claims process.

## Features
- Search for conditions and CFR references.
- Add tasks and manage a workspace.
- Auto-save functionality for progress tracking.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/va-cfr-mvp.git


2. Install dependencies: npm install

3. Start dev server: npm run dev

4. Browser: http://localhost:3000
